# UNSEEN prototype status

This branch contains an initial module scaffold for an evidence-first contradiction benchmark. The smoke fixtures are synthetic. The solver is heuristic, not a foundation model. Any scores from these fixtures are software-pipeline checks only; they do not support claims that graph reasoning outperforms modern AI.

The target experiment compares text-only, graph-structured, structured-text, and graph-ablation arms under matched source, model, prompt, context, and tool budgets. See the experiment protocol for metrics, controls, and falsification requirements.
